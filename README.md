# Tip & Sign

A fake restaurant tip + signature screen that looks real, lets people actually sign, and then **never completes the transaction**.

Built for a Halloween costume where I dressed as a server and handed people an iPad.

## What it does

- Realistic tip selection (15%, 18%, 20%, 25%, custom, or no tip)
- Double-tap the bill total to edit the amount — tips update automatically
- Working signature pad (draw with finger)
- “Done” starts an authorization that never finishes
- Messages get progressively more unhinged the longer you wait
- After two minutes a “Try Again” button appears so you can restart the bit

## How to use

1. Open `index.html` on an iPad or iPhone (or host it somewhere)
2. In Safari: Share → Add to Home Screen for a more app-like feel
3. Hand it to someone and watch them try to tip

Works offline once loaded. Optimized for iPad and iPhone (portrait and landscape).
